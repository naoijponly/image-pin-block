# Image Pin Block

画像の上にラベル付きのピンを配置し、クリックやタップで説明を表示したり、同じページ内の見出しなどへジャンプできるようにする WordPress の Gutenberg ブロックです。アプリ紹介ページのスクリーンショットのように、画像の各部分から対応する説明箇所へ誘導する用途を想定して作られました。ビルドツールを使わない素の JavaScript / PHP / CSS で実装されています。

## 主な機能

- 画像上の好きな位置にピンを追加し、ドラッグで位置調整(画像に対する%座標で保存されるため、表示サイズが変わっても相対位置を保ちます)
- ピンごとに、近くに常時表示する**ラベル**・クリックやタップで表示する**説明文**・同じページ内の見出し等への**遷移先**を設定できます
- ラベルはドラッグで、ピン/マーカーの周囲360度好きな位置へ配置できます
- **マーカー画像**: ピンごとに丸マーカーの代わりに任意の画像を指定できます。拡大率(元画像サイズを基準にした%)とラベル表示の有無を個別に設定できます
- PC / スマホでそれぞれ独立した動作設定(ホバー・クリック・タップの組み合わせ)を選べます
- ピンの追加・編集はすべて専用のフルスクリーン編集画面(Fullscreen Editor)で行います。ダブルクリックで新規ピンの追加位置を確認してから作成する、といった誤操作を防ぐ導線になっています
- 現在の状態を元画像の解像度でPNG画像として書き出せます(「画像として保存」)
- ピンのサイズ・色・ラベル/ポップオーバーの背景色・不透明度・文字色・縁取りを、WordPress 標準のカラーピッカー等で設定可能
- 画像の拡大表示(Lightbox): テーマのLightbox機能には依存しない自前実装です。ドラッグ/スワイプでの移動、マウスホイール/ピンチ/画面上のボタンでの拡大縮小に対応しています(この拡大表示は上記のFullscreen Editorとは別の、フロント表示側の機能です)
- ビルドツール不要(webpack 等を使わない素の JavaScript / PHP / CSS)

## インストール

### 方法A: GitHub Releases から ZIP をダウンロード

1. このリポジトリの [Releases](../../releases) ページから最新の ZIP ファイルをダウンロードします
2. WordPress 管理画面の「プラグイン」→「新規追加」→「プラグインのアップロード」から ZIP ファイルを選択してインストールします
   - または、ZIP を解凍して `wp-content/plugins/image-pin-block` フォルダとして直接配置しても構いません
3. プラグイン一覧から「Image Pin Block」を有効化します

### 方法B: git clone

```bash
cd wp-content/plugins
git clone <このリポジトリのクローン用URL> image-pin-block
```

`<このリポジトリのクローン用URL>` は、GitHub の「Code」ボタンから取得できる URL に置き換えてください。配置後、WordPress 管理画面のプラグイン一覧から「Image Pin Block」を有効化します。

## 基本的な使い方

1. 投稿・固定ページの編集画面で、ブロック挿入メニューから「Image Pin Block」を追加します
2. 「画像を選択」ボタンから、メディアライブラリの画像(PNG / JPEG)を選びます
3. 画像を選択すると、通常のGutenbergブロック上には表示専用のプレビューが表示されます。ピンの追加・編集は、右サイドバーの「ピンを編集」ボタン、または画像のダブルクリックで開くフルスクリーン編集画面(Fullscreen Editor)の中で行います
4. Fullscreen Editor内のPreview上で、画像の何もない場所を**ダブルクリック**すると、その位置に「ここにピンを追加」というメニューが表示されます。押すとその位置にピンが追加されます(単クリックでは追加されません。ピン一覧の「＋」ボタンからも画像中央に追加できます)
5. 追加したピンは、Fullscreen Editor下部の「個別設定」で以下を編集できます
   - **ラベル**: ピンの近くに常時表示される短い文字列
   - **説明**: ポップオーバー(PC)/説明パネル(スマホ)に表示される説明文
   - **遷移先**: ピンを押したときに移動する先。同じページ内の見出しブロックをプルダウンから選ぶか、アンカー名を直接入力します
6. ピンはPreview上のドラッグで位置を調整できます。ラベルもドラッグでピンの周囲の位置を調整できます
7. ピンをもう一度クリックすると、その場でポップオーバーの表示を確認できます(1回目のクリックは選択のみ、選択済みのピンへの2回目以降のクリックでポップオーバーが開閉します)
8. Fullscreen Editor右側の「ブロック全体の設定」パネルで、PC での動作(ホバーで説明表示してクリックで遷移 / クリックで説明表示して説明内のリンクで遷移)と、スマホでの動作(タップで即遷移 / 1回目タップで説明・2回目タップで遷移 / タップで説明表示して説明内のリンクで遷移)を、それぞれ独立して選べます
9. 同じパネルで、ピンのサイズ・色(丸マーカーのみ)、ラベル/ポップオーバーそれぞれの背景色・背景の不透明度・文字色・縁取りも設定できます
10. 編集が終わったら「編集を反映して終了」(または右上の×)でFullscreen Editorを閉じます。これはブロックの属性へ編集内容を反映するだけで、投稿そのもののサーバー保存にはなりません。最後に**投稿・固定ページ側の「更新」「公開」等**で保存してください

## 主な編集操作(Fullscreen Editor)

- **Pin/Markerの追加**: 空き部分のダブルクリック、または「＋」ボタン
- **Pin/Markerの選択**: 1回クリック(選択のみ、ポップオーバーは開きません)
- **ポップオーバーの表示**: 選択済みのPin/Markerをもう一度クリック(トグル)
- **移動**: Pin/Marker/Labelをドラッグ
- **マーカー画像の拡大率変更**: リサイズハンドルをドラッグ、または数値入力
- **削除**: 「このピンを削除」(削除後は次のピン、無ければ前のピンを自動選択)
- **Zoom**: Preview右上のスライダー、またはPreview上でのマウスホイール操作(100〜200%)
- **Pan**: 100%を超えるZoom時、Preview上のドラッグ
- **全体を表示する**: 現在のPreview寸法に画像全体を収める
- **画像として保存**: 現在のPin/Marker/Labelの状態を元画像へ合成したPNGとして保存

## Frontend(投稿ページ側の表示)

- PCでの動作は「ホバーで説明表示、クリックで遷移」「クリックで説明表示、説明内のリンクで遷移」から選べます
- スマホでの動作は「タップで即遷移」「1回目タップで説明表示、2回目タップで遷移」「タップで説明表示、説明内のリンクで遷移」から選べます
- 説明文(Description)が空で遷移先(target)だけが設定されているピンは、上記いずれの設定でも説明表示の段階を飛ばして遷移先へ直接移動します
- 画像右上の拡大ボタンから、自前実装の拡大表示(Lightbox)を開けます。ドラッグ/スワイプでの移動、マウスホイール/ピンチ/画面上のボタンでの拡大縮小に対応しています

## 対応環境

- WordPress のブロックエディタ(Gutenberg)
- Cocoon(クラシックテーマ、子テーマ有効)での動作を確認しています

Pointer Events や `<template>` 要素、CSS の `transform` などを使用しているため、モダンブラウザでの利用を前提としています。`Requires at least` / `Tested up to` / `Requires PHP` 等の詳細な対応バージョンは [`readme.txt`](readme.txt) を参照してください。

## 既知の制限事項

- 対応する画像形式は PNG / JPEG のみです(SVG は非対応です)
- 表示言語は英語(ソースコードの既定言語)と日本語(`languages/image-pin-block-ja.*` による翻訳)に対応しています。編集画面・フロント側(拡大表示のボタン類を含む)とも翻訳対象です
- アンカー名を直接入力する場合、ページ内の他の要素と同じ ID(アンカー名)が重複していると、意図しない場所へ移動することがあります(ブラウザは最初に見つかった要素へ移動するため)
- 拡大表示中の移動・拡大縮小はマウス / タッチ操作を前提としており、キーボードのみでの操作には対応していません(閉じる操作のみ Esc キーに対応しています)
- Fullscreen EditorのPreview上でのタッチ操作は、1本指でのPin/Marker/Label移動・Panのみに対応しています(2本指ピンチによるZoomには対応していません)
- 画像が選択されていない、またはピンが1つも無いブロックは、フロント側には何も出力されません
